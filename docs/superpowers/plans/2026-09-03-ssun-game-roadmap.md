# SSun Game Implementation Roadmap

**Spec:** `docs/superpowers/specs/2026-09-03-ssun-game-platform-design.md`

SSun Game은 독립적으로 검증 가능한 아래 계획으로 나누어 구현한다. 각 계획이 완료되고 승인된 뒤 다음 계획을 상세화한다.

1. **디자인 시스템과 반응형 9-max 테이블**  
   SSun Game 브랜드 자산, 세로 로비 셸, 가로·세로 게임 테이블, 카드·칩·좌석·액션 그래픽.
2. **권위 게임 서버와 다중 테이블**  
   완전한 핸드 생명주기, 타임뱅크, 관전자, 재접속, 테이블 소유권과 복구.
3. **계정·영속화·실시간 인프라**  
   게스트 및 소셜 연동, PostgreSQL, Redis, 세션, 버전 관리.
4. **경제·결제·링게임 로비**  
   이중 기입 원장, 스토어 영수증, 보상, 링게임 매칭과 방 목록.
5. **Sit & Go와 MTT**  
   등록, 좌석 배정, 블라인드·브레이크, 테이블 병합, 탈락·순위·보상.
6. **시즌·랭킹·소셜**  
   퀘스트, 시즌 패스, 프로필, 전적, 친구, 채팅, 신고.
7. **운영·위험 관리·출시**  
   운영자 콘솔, 감사, 봇·담합 탐지, 부하·복구 검증, 스토어 출시.

각 계획은 이전 계획이 제공하는 공개 인터페이스만 사용하며, 후속 계획 때문에 완료된 모듈의 내부를 임의로 결합하지 않는다.
