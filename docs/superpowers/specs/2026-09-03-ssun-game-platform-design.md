# SSun Game 플랫폼 설계

작성일: 2026-09-03  
상태: 사용자 검토 대기

## 1. 목표

SSun Game은 한국어 사용자를 위한 성인 전용 소셜 텍사스 홀덤 플랫폼이다. Android와 iOS 앱, PC 웹을 지원하며 일반 링게임, Sit & Go, 대규모 MTT를 제공한다. 무료 게임 재화와 인앱 결제를 사용하고 게임 재화의 현금 환전은 제공하지 않는다.

제품 경험은 글로벌 토너먼트 포커 앱의 깊이와 상용 게임 수준의 그래픽 완성도를 목표로 한다. 참고 제품의 상표, 로고, 캐릭터, 원화를 복제하지 않고 SSun Game의 독자 IP를 사용한다.

## 2. 확정된 제품 원칙

- 브랜드명은 **SSun Game**이다. 폐기된 임시명 KPL은 사용하지 않는다.
- 로고는 승인된 2번 안인 검정·금색·적색 포커칩 메달리온과 더블 S 심벌을 기준으로 한다.
- 초기 서비스 언어는 한국어다. 문자열은 코드와 분리해 향후 다국어 확장을 허용한다.
- 서비스는 19세 이상 성인 전용이다.
- 로그인은 게스트 시작과 카카오, Google, Apple 계정 연동을 지원한다.
- 수익 모델은 게임 칩, 시즌 패스, 코스메틱 인앱 결제와 선택형 보상 광고다. 강제 전면 광고는 사용하지 않는다.
- 게임 종목은 텍사스 홀덤에 집중한다.
- 게임 모드는 링게임, Sit & Go, MTT다.
- 테이블은 2~9명의 동적 좌석을 지원하고 풀링 기본값은 9-max다.

## 3. 사용자 경험

### 3.1 화면 방향

- 모바일 로비와 계정·상점·대회 상세 화면은 세로형을 기본으로 한다.
- 모바일 게임 테이블은 가로형과 세로형을 모두 지원한다.
- PC 웹 게임 테이블은 가로형을 기본으로 한다.
- 화면 회전 중에도 현재 핸드, 베팅 입력, 타이머 상태가 보존되어야 한다.

### 3.2 주요 흐름

1. 앱 시작 및 연령 확인
2. 게스트 시작 또는 소셜 계정 로그인
3. SSun Game 홈 로비
4. 링게임, Sit & Go, MTT 선택
5. 방 또는 대회 상세 확인과 참가
6. 최대 9인 게임 테이블 입장
7. 핸드 결과와 보상·랭킹 반영
8. 프로필, 전적, 상점, 시즌, 고객지원 이용

### 3.3 로비

세로형 홈 로비는 다음 영역을 포함한다.

- 상단 프로필, 게임 재화, 알림, 설정
- 대형 시즌·대회 이벤트 배너
- 사용자 상태에 따른 추천 게임과 빠른 참가
- 링게임, Sit & Go, MTT 진입점
- 진행 중인 이벤트와 방송·커뮤니티 콘텐츠
- 홈, 게임, 대회, 시즌·랭킹, 프로필 하단 내비게이션

### 3.4 게임 테이블

테이블은 참고 화면의 높은 정보 밀도와 프리미엄 카드룸 분위기를 따른다.

- 따뜻한 우드 배경, 검은 펠트, 입체 카드·칩·좌석 패널
- 2~9인 동적 좌석 배치와 영웅 좌석 강조
- 닉네임, 아바타, 국가 또는 지역 표시, 레벨, 스택, 바운티
- 홀카드, 커뮤니티 카드, 메인팟과 사이드팟
- 딜러 버튼, 블라인드·앤티, 현재 차례와 타임뱅크
- 폴드, 체크·콜, 레이즈 및 2BB·3BB·4BB·팟 빠른 입력
- 채팅, 이모티콘, GIF, 자리비움, 다음 핸드 자리비움
- 핸드 기록, 게임 규칙, 테이블 설정
- 상대 통계 VPIP, PFR, ATS, 3BET과 사용자 메모
- 카드 딜, 칩 이동, 올인, 쇼다운, 승자, 탈락 연출과 효과음

가로형은 테이블 전체와 9개 좌석을 한 화면에 배치한다. 세로형은 테이블 장축을 세로로 배치하고 액션 패널과 상세 메뉴를 하단 시트로 제공한다.

### 3.5 대회

MTT 상세와 진행 화면은 다음을 제공한다.

- 시작 시각, 시작 칩, 바이인, 보장 상금, 참가자 수
- 블라인드·앤티 단계, 다음 단계와 브레이크 시간
- 늦은 등록, 리엔트리, 바운티 규칙
- 전체·잔여 인원, 현재 순위, 평균·최대·최소 스택
- 참가자, 테이블, 채팅, 위성 대회 탭
- 대회 등록 확인과 티켓·게임 재화 결제
- 테이블 이동과 좌석 재조정

## 4. 그래픽 및 브랜드 시스템

- 로비는 검정과 금색 중심의 글로벌 대회 분위기를 사용한다.
- 테이블은 따뜻한 우드, 검은 펠트, 앤티크 골드, 절제된 적색과 청록색 정보 텍스트를 사용한다.
- 승인된 더블 S 심벌은 앱 아이콘, 로딩 화면, 게임 칩과 테이블 브랜딩에 사용한다.
- 워드마크는 로그인, 로비, 대회 배너에 사용한다.
- 모든 캐릭터, 아바타, 트로피, 배너, 카드 뒷면은 독자 제작한다.
- 카드 숫자, 스택, 팟, 액션 버튼은 작은 모바일 화면에서도 장식보다 가독성을 우선한다.
- 원본 그래픽은 화면 배경, UI 9-slice, 아이콘, 카드, 칩, 아바타, 이펙트 시퀀스로 분리한다.

## 5. 시스템 아키텍처

초기 구조는 TypeScript 기반 모듈형 서버다. 하나의 배포 단위 안에서 도메인 경계를 분명히 하고, 측정된 트래픽과 장애 격리 필요가 생기면 해당 모듈만 독립 서비스로 분리한다.

### 5.1 클라이언트

- Expo/React Native 기반 Android·iOS 앱
- 동일한 도메인 모델과 디자인 토큰을 공유하는 PC 웹
- 서버가 승인한 공개 상태만 렌더링하는 수동 클라이언트
- 로컬 캐시는 화면 복원과 정적 자산에만 사용하며 게임 판정에는 사용하지 않는다.

### 5.2 서버 모듈

- **접속 관문:** 인증, 세션, 버전 검사, 속도 제한
- **계정:** 게스트, 소셜 연동, 연령 상태, 프로필, 기기 관리
- **로비:** 게임 목록, 추천, 빠른 참가, 온라인 인원
- **매칭:** 링게임과 Sit & Go 대기열, 좌석 배정
- **게임:** 권위 테이블, 액션 검증, 타이머, 핸드 생명주기
- **토너먼트:** 등록, 블라인드 구조, 테이블 생성·병합, 순위와 보상
- **경제:** 지갑, 이중 기입 원장, 구매, 보상, 티켓
- **시즌·랭킹:** 경험치, 리그, 퀘스트, 시즌 패스
- **소셜:** 친구, 채팅, 이모티콘, 신고
- **운영:** 공지, 대회 구성, 제재, 재화 보정, CS와 감사
- **위험 관리:** 다중 계정, 봇, 담합, 비정상 액션 탐지

### 5.3 저장소

- **PostgreSQL:** 계정, 연동 정보, 재화 원장, 구매, 대회, 보상, 제재, 감사 기록
- **Redis:** 세션, 매칭 대기열, 테이블 라우팅, 타이머, 재접속 토큰, 단기 상태
- **Object Storage:** 아바타, 이벤트 배너, 리플레이, 장기 로그와 정적 자산

## 6. 게임 데이터 흐름

1. 클라이언트가 액션 의도를 WebSocket으로 전송한다.
2. 접속 관문이 세션, 버전, 요청 빈도와 중복 키를 확인한다.
3. 권위 게임 서버가 차례, 액션 가능 여부, 금액 범위를 검증한다.
4. 게임 엔진이 새 상태를 계산한다.
5. 서버가 액션 이벤트를 기록하고 주기적으로 핸드 스냅샷을 저장한다.
6. 각 플레이어에게 권한에 맞는 공개 상태와 본인 홀카드만 전송한다.
7. 핸드 종료 시 경제 모듈이 멱등성 키를 이용해 보상 원장을 반영한다.

셔플, 딜, 승패 판정은 서버에서만 수행한다. 다른 플레이어의 홀카드나 덱 순서는 클라이언트에 전송하지 않는다.

## 7. 재화와 결제

- 지갑 잔액은 직접 수정하지 않고 원장 항목의 합으로 산출한다.
- 모든 구매, 보상, 참가비, 상금에는 유일한 멱등성 키를 부여한다.
- 앱스토어 영수증은 서버가 검증한 뒤 재화를 지급한다.
- 환불과 취소는 반대 방향 원장 항목으로 기록한다.
- 운영자 재화 보정은 사유, 담당자, 이전·이후 값과 승인 이력을 남긴다.
- 게임 재화는 현금 또는 현금성 상품으로 환전할 수 없다.

## 8. 장애 및 복구

- 연결이 끊기면 재접속 토큰으로 동일 계정과 테이블을 복원한다.
- 제한 시간 안에 복귀하지 못하면 규칙에 따라 자동 체크 또는 폴드한다.
- 토너먼트 참가와 칩 스택은 연결 해제와 무관하게 유지된다.
- 진행 핸드는 이벤트 기록과 스냅샷으로 복원한다.
- 동일 액션 재전송과 결제 콜백 중복은 멱등하게 처리한다.
- 다중 서버 환경에서는 테이블 소유권을 단일 인스턴스에 부여하고 임대 만료 후 안전하게 승계한다.
- 복구 불가능한 핸드는 운영 규칙에 따른 무효 처리와 보상 절차를 감사 로그와 함께 수행한다.

## 9. 성인 보호와 보안

- 가입 시 연령 상태를 확인하고 성인 전용 정책을 고지한다.
- 플레이 시간과 결제 한도, 휴식 알림, 자가 제한, 계정 잠금 기능을 제공한다.
- 인증 토큰과 결제 정보는 클라이언트 로그에 남기지 않는다.
- 동시 로그인, 루팅·변조 클라이언트, 비정상 요청 빈도와 조작된 액션을 탐지한다.
- 담합 탐지는 동일 테이블 반복 동석, 칩 이동, 폴드·레이즈 상관관계와 네트워크 신호를 결합한다.
- 사용자 신고와 자동 탐지 결과는 운영자 검토와 이의 제기 이력을 보존한다.

## 10. 테스트

### 10.1 게임 엔진

- 베팅 순서, 최소·최대 레이즈, 올인, 블라인드와 앤티
- 메인팟·다중 사이드팟, 동률, 홀수 칩 분배
- 프리플랍부터 쇼다운까지 모든 종료 경로
- 2~9인 좌석과 탈락·자리비움 상태

### 10.2 실시간·복구

- 동시 접속과 중복 액션
- 느린 네트워크, 연결 단절, 재접속, 타임아웃
- 프로세스 재시작과 테이블 소유권 승계
- 비인가 카드 정보가 노출되지 않는지 계약 테스트

### 10.3 토너먼트

- 등록, 취소, 늦은 등록, 리엔트리, 탈락과 우승
- 블라인드 상승, 브레이크, 테이블 병합과 좌석 이동
- 수천 명 규모 가상 참가자 부하 시뮬레이션
- 보상 순위와 동률 처리

### 10.4 결제·경제

- 중복 콜백, 네트워크 재시도, 환불과 취소
- 참가비·상금·퀘스트 보상의 원장 불변식
- 운영자 보정 권한과 감사 기록

### 10.5 클라이언트

- Android, iOS, PC 웹
- 모바일 세로 로비와 가로·세로 테이블
- 안전 영역, 작은 화면, 태블릿, 회전과 글자 확대
- 카드·좌석·팟·액션바 겹침과 프레임 성능
- 사운드, 햅틱, 애니메이션 감소 접근성 설정

## 11. 운영과 배포

- 개발, 스테이징, 운영 환경을 분리한다.
- 데이터베이스 마이그레이션, 서버와 클라이언트 호환 버전을 관리한다.
- 자동 배포에는 테스트, 점진 배포, 상태 점검과 롤백을 포함한다.
- 지표는 접속 성공률, 매칭 시간, 핸드 완료율, 재접속 성공률, 결제 오류율을 추적한다.
- 오류 추적, 구조화 로그, 분산 추적과 경보를 구성한다.
- 운영자 콘솔에서 공지, 대회, 사용자 제재, 재화 보정, CS, 장애 상태를 관리한다.

## 12. 기존 코드 활용과 변경 경계

- `packages/poker-engine`의 순수 게임 규칙과 테스트 방식을 유지·확장한다.
- `packages/shared`는 버전이 명시된 서버·클라이언트 계약을 담당한다.
- `apps/server`는 현재 단일 테이블 스켈레톤에서 모듈형 플랫폼 서버로 확장한다.
- `apps/mobile`은 로그인·로비·게임 흐름을 유지하되 SSun Game 디자인 시스템과 반응형 방향 전환을 적용한다.
- 기존 로컬 봇 모드는 개발·회귀 테스트용 샌드박스로 유지한다.

## 13. 단계적 구현

완전한 구조를 먼저 정의하되, 위험을 통제하기 위해 다음 순서로 구현한다.

1. SSun Game 디자인 시스템과 가로·세로 9-max 테이블
2. 권위 게임 서버의 핸드 생명주기, 재접속과 다중 테이블
3. 계정, PostgreSQL, Redis, 재화 원장

## 14. 성공 기준

- 2~9인 링게임, 2·6·9인 Sit & Go와 9-max MTT가 서버 권위 방식으로 정상 완료된다.
- 연결 해제 후 사용자가 동일 좌석과 대회 상태로 복귀한다.
- 결제·보상 재시도에도 재화가 중복 지급되거나 차감되지 않는다.
- Android·iOS·PC 웹에서 동일 계정과 게임 상태를 사용한다.
- 모바일 세로 로비와 가로·세로 테이블에서 핵심 정보가 겹치지 않는다.
- 참고 제품 수준의 시각적 밀도와 연출을 가지면서 SSun Game의 독자 브랜드를 유지한다.
- 운영자가 대회, 사용자, 경제와 장애를 감사 가능한 방식으로 관리한다.
